## 📦 Install or update

1. Under [ResonaDeck 1.5.7](https://github.com/ValentineBSAA/ResonaDeck/releases/tag/1.5.7) download **[ResonaDeck-1.5.7.zip](https://github.com/ValentineBSAA/ResonaDeck/releases/download/1.5.7/ResonaDeck-1.5.7.zip)** from **Assets**.
2. Install with Decky Loader's manual ZIP installation option. Leave persistent settings intact during a normal update.
3. Open **Quick Access → ResonaDeck**, connect Plex/Jellyfin and select your media library.
4. A full Steam Deck reboot is **not normally required**. If Steam retains old styling or plugin hooks, close/reopen Quick Access and restart Steam if necessary.

### 🌈 GTM visualizer control

When paired with GTM 4.6.7, ResonaDeck music has audio priority over GTM Store/ambient playback. An **ON** visualizer setting allows visuals during eligible playback; it does not force an idle visualizer on screen. **OFF** hides visualizations without pausing the track.

If visuals appear but stay static or fail to follow the music, open **Quick Access → ResonaDeck → GTM Visualizers** and turn sharing **OFF then ON**. A successful reconnect restored music reactivity in maintainer testing. Diagnostics are in **Full ResonaDeck → Settings → GTM Visualizers · Live Control**. [Support guide](SUPPORT.md).
