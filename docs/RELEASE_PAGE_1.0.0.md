# 🎧 ResonaDeck 1.0.0
### Your Plex audio library, right where you play.

**The first stable release of ResonaDeck for Steam Deck and Decky Loader.**

## ⬇️ Download & install

**[Download ResonaDeck-1.0.0.zip](https://github.com/ValentineBSAA/ResonaDeck/releases/download/1.0.0/ResonaDeck-1.0.0.zip)**

1. Install [Decky Loader](https://github.com/SteamDeckHomebrew/decky-loader) on Steam Deck.
2. Open Decky Loader → **Settings → Developer → Install Plugin ZIP**.
3. Select the downloaded ZIP and open ResonaDeck from the Quick Access Menu.
4. Sign into Plex, choose your server, and start listening to **your own** media.

**Requires:** Steam Deck, Decky Loader, and access to a Plex Media Server. ResonaDeck does not supply music or other media.

## ✨ What you get

- 🎶 **Music, audiobooks, podcasts and More Audio** from Plex.
- 🎨 **Art-colored frosted glass** for the player and queue, plus distinct library color palettes.
- 🎮 **Controller-first Quick Menu**: A plays, X opens media actions, and the D-pad navigates controls.
- 📚 **Full Manager** with shelves, albums, authors, chapters, playlists, media details, and search.
- ➕ **Add to Queue / Play Next**, live total-track counter, Shuffle and Repeat.
- 🔖 **Audiobook chapters and resume**, with dedicated long-form playback controls.
- 🧩 Designed to coexist with Steam and **CSS Loader** themes.

### From 0.9.50 to 1.0.0

This is the same **hardware-tested 0.9.50 baseline**, promoted to 1.0.0 with updated public packaging and documentation. No experimental redesign was introduced.
