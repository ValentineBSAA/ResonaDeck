# 🎧 ResonaDeck 1.2.1 Stable

**Your Plex audio library, right where you play.** ResonaDeck provides music, audiobooks, podcasts, and other Plex audio in Steam Deck's Quick Access Menu and Full Manager.

## 🆕 New in 1.2.1: Easier updates

- **Direct Updater support:** ResonaDeck now supplies canonical GitHub repository metadata, helping the independent [Decky Direct Updater](https://deckyup.nukeador.com/) find the correct official source.
- **Consistent identity:** Release version `1.2.1` is synchronized between the plugin manifest, package metadata, frontend display and backend fallback.
- **Compatible ZIP:** The [published stable release](https://github.com/ValentineBSAA/ResonaDeck/releases/tag/1.2.1) includes a single, installable `ResonaDeck-1.2.1-Stable.zip` asset.
- **Manual installs still work:** Direct Updater is completely optional.

**This is a distribution maintenance release, not a playback redesign.** Surprise Me, Keep Playing, Favorites, configurable music crossfade, XFADE indicators, animated vinyl handoff, Plex browsing, controller navigation and artwork-colored glass remain as before.

## ⬇️ Install or update

**Option A: Direct Updater.** Install [Decky Direct Updater](https://deckyup.nukeador.com/), search for **`ValentineBSAA/ResonaDeck`**, choose the official repository, select Install or Update and confirm. An older 1.2.0 installation may request a one-time source confirmation. Nothing installs without confirmation.

**Option B: Manual ZIP.** Download [ResonaDeck-1.2.1-Stable.zip](https://github.com/ValentineBSAA/ResonaDeck/releases/download/1.2.1/ResonaDeck-1.2.1-Stable.zip). Enable Developer Mode in Decky Settings → General, then select Developer → Install Plugin from ZIP.

## 🎮 Controller quick start

Focus the gold Surprise Me turntable. Press **A** to start and **X** to open or close settings. When music is playing, **X** on the active album artwork opens those settings without stopping music. On regular library items, **X** continues opening media actions such as Add to Queue, Play Next, or Browse Details.
